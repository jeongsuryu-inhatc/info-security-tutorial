# 정답지 모음 — 1·2·3·6·9·10주차 (조교용)

분석/설정 위주 주차의 기대 답안 요지. (코드 주차 4·5·7·8은 `shopguard-app-secure/`, 자동채점은 `grading/`)

## 1주차 — 정보보안의 세계
- **CIA 분류 예시**: 랜섬웨어=가용성, 데이터 위변조=무결성, 개인정보 유출=기밀성. 3건이 서로 다른 요소여야 함.
- **자산 CIA 매핑**(`shopguard-cia.csv`): 자산마다 C·I·A 셋 다 점수, primary 는 성격별로 다름
  (이미지서버=A, 결제·카탈로그=I, 회원DB=C). 전부 C로 찍으면 감점. 근거는 침해 시나리오로.
- 감점: 출처 없는 사례, "해킹=기밀성" 단순화.

## 2주차 — 시스템보안
- **Lynis 하드닝 지수 상승**이 핵심 증빙(Before<After). 상위 기여 조치 예: 불필요 서비스 제거, SSH 강화, 방화벽 deny 기본값.
- 체크리스트 10항목 각각 **적용 명령**이 기재돼야 함(개념만 쓰면 감점).
- 흔한 실수: 서비스 stop만 하고 disable 안 함 / SSH 키 미등록 후 비번인증 차단.

## 3주차 — 네트워크보안
- **평문 노출 목록**: username/password(자격증명), 세션 쿠키, 검색어 등. HTTPS 전환 시 본문은 보호되나 목적지 IP·SNI·패킷 크기는 여전히 노출됨을 서술해야 만점.
- **방화벽**: 기본 deny + 필요한 포트만 allow. nmap Before(다수 open)/After(최소) 비교.
- 감점: pcap에서 자격증명 위치를 못 짚음 / 모든 포트 개방 유지.

## 6주차 — 악성코드
- EICAR SHA-256 = `275a021b...fd0f` (제공 룰셋과 일치해야 함).
- 스캐너는 **해시 매칭 + 문자열 룰** 둘 다 있어야 함(모범: `shopguard-app-secure/scanner.js`).
- 시그니처 한계: 변종/패킹/제로데이 미탐 → 행위기반·휴리스틱 필요. 이 서술 있으면 가점.
- **안전수칙 위반(호스트에서 샘플 오픈)은 감점·재제출.**

## 9주차 — 보안시스템
- 커스텀 룰 3종(SQLi/포트스캔/로그인 브루트포스) 모두 **동작 + sid 고유**. 모범 룰: `solutions/week09-local.rules`.
- **오탐 튜닝**: 정상 pcap 재생 시 오탐 1건 이상 찾아 content 정밀화/threshold 조정, Before/After 탐지수 비교.
- 감점: `content:"SELECT"` 처럼 광범위해 오탐 폭증 / sid 중복으로 룰 로드 실패.

## 10주차 — IoT·AI보안
- **IoT**: 무인증 MQTT 도청으로 `token=SECRET-DEVICE-TOKEN-123` 확인 → `allow_anonymous false` + password_file/ACL 로 완화, 재도청 실패 증빙.
- **AI**: epsilon 증가에 따라 오분류 발생 임계값 기록 + epsilon-오분류율 그래프. 방어(입력 전처리/adversarial training) 전후 비교.
- 감점: epsilon 과도(육안으로 깨진 이미지 — 적대적 예제 핵심은 "사람 눈엔 정상") / 정규화 스케일 오류.
