### Lab 1-A. 개인 노출 셀프 진단 (25분)

**Step 1.** 브라우저에서 [`https://haveibeenpwned.com`](https://haveibeenpwned.com) 에
**본인 이메일**을 조회하고, 유출된 서비스와 유출 데이터 종류를 기록한다.

**Step 2.** 비밀번호 유출 여부는 **전체 비밀번호를 보내지 않는** k-익명성 API로 안전하게 확인한다.
아래는 예시 비밀번호 `password123`의 SHA-1 앞 5자리만 서버로 보내고, 나머지는 로컬에서 대조한다.
```bash
# 확인할 (과거 폐기한) 비밀번호를 PW 에 넣는다. 현재 쓰는 비밀번호는 입력 금지.
PW='password123'
HASH=$(printf '%s' "$PW" | openssl sha1 | awk '{print toupper($2)}')
PREFIX=${HASH:0:5}; SUFFIX=${HASH:5}
curl -s "https://api.pwnedpasswords.com/range/$PREFIX" | grep -i "$SUFFIX" \
  && echo "→ 유출된 비밀번호 (횟수는 콜론 뒤 숫자)" || echo "→ 목록에 없음"
```

**Step 3.** Google 도킹으로 본인 이름/닉네임의 공개 노출을 3건 찾는다.
아래 쿼리를 **검색창에 복사**해 `홍길동`/`닉네임` 부분만 본인 값으로 바꾼다.
```text
"홍길동" filetype:pdf
"홍길동" (email OR 이메일 OR 전화)
site:github.com 닉네임
intext:"본인학번 또는 전화번호"
```
발견한 항목의 URL·노출 정보를 `week01/report.md`에 기록한다.

## 4. 주간 과제 (2시간)

### 과제 1. 침해 사례 수집·분류

- 최근 3년 내 보안 침해 사례 **3건**을 뉴스/보고서에서 수집한다.
- 각 사례에 대해 표로 정리: **사건 요약 / 침해된 CIA 요소 / 공격 방식 / 피해 규모 / 방지책**.
- 3건은 서로 다른 CIA 요소가 주로 침해된 사례여야 한다(기밀성만 3건 ✗).

### 과제 2. ShopGuard 자산 CIA 매핑

강의가 제공하는 `starter/shopguard-assets.csv`(자산명·설명만 있는 초안)의 각 자산에
**CIA 3요소별 중요도 점수와 우선순위·근거**를 채워 `week01/shopguard-cia.csv`로 제출한다.

**작성 규칙**
- 각 자산에 대해 C·I·A **세 요소 모두** 1~5로 평가한다
  (1=거의 무관, 3=보통, 5=치명적). 한 요소만 적는 것은 오답이다.
- 세 점수 중 자산의 성격상 가장 중요한 것을 `primary`(C/I/A)로 지정한다.
- `rationale`은 **침해 시나리오로** 쓴다: "유출되면 →", "위변조되면 →", "다운되면 →".
- `asset_id`는 **13주차 위험평가 매트릭스와 연결**되므로 보관한다.

**CSV 스키마 (열 순서 고정)**

| 열 | 의미 | 값 |
|---|---|---|
| `asset_id` | 자산 고유 ID | `A01`, `A02` … |
| `asset_name` | 자산명 | 회원 DB, 결제 모듈 등 |
| `description` | 담는 데이터·기능 | 자유서술 |
| `data_held` | 처리하는 핵심 데이터 | 예: 이메일·비밀번호 해시 |
| `C` / `I` / `A` | 기밀성·무결성·가용성 중요도 | 각 1~5 |
| `primary` | 셋 중 가장 중요한 요소 | `C` / `I` / `A` |
| `rationale` | primary 지정 근거 (한 줄) | 침해 시나리오 서술 |

**작성 예시**

```csv
asset_id,asset_name,description,data_held,C,I,A,primary,rationale
A01,회원 DB,고객 계정 정보,이메일·비밀번호 해시·주소,5,4,3,C,유출 시 개인정보 침해가 가장 치명적
A02,결제 모듈,주문 결제 처리,카드 토큰·결제 금액,4,5,4,I,금액 위변조 시 직접 금전 피해
A03,상품 이미지 서버,상품 사진 정적 제공,공개 이미지,1,2,4,A,다운되면 판매 중단되나 데이터 민감도는 낮음
A04,관리자 콘솔,운영 관리 인터페이스,전체 제어 권한,4,5,4,I,장악 시 데이터·주문 임의 조작 가능
A05,상품 카탈로그 DB,상품·가격 정보,가격·재고,2,5,4,I,가격 무결성 훼손은 8주차 가격조작으로 연결
A06,인증/세션 서비스,로그인·세션 관리,세션 토큰,4,4,5,A,장애 시 전 사용자 로그인 불가
A07,접근/에러 로그,서버 로그 보관,접속 기록·IP,3,4,3,I,변조되면 11주차 포렌식 신뢰성 붕괴
```

> 위 예시는 형식 이해용 샘플이다. 학생은 제공된 자산 목록 전체에 대해
> 스스로 점수와 근거를 판단해 작성한다(예시 값을 그대로 복사 금지).

## 7. 흔한 오류 / 확장 과제

**흔한 오류**
- "해킹당함 = 기밀성 침해"로 단순화. 랜섬웨어는 가용성, 데이터 위변조는 무결성 침해다.
- 출처 없는 요약. 반드시 기사/보고서 링크를 남긴다.

**확장 과제 (심화)**
- 선택한 사례 1건을 **공격 킬체인(정찰→침투→확산→목적달성)** 단계로 재구성한다.
- 본인 계정에 대해 **비밀번호 관리자 도입 + 2FA 활성화**를 실제로 적용하고
  Before/After 보안 상태를 캡처한다.
