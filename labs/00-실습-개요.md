# 정보보안개론 실습 시리즈 — 전체 개요

## 관통 시나리오: ShopGuard

이 실습 시리즈는 가상의 온라인 쇼핑몰 **ShopGuard**를 학기 전체의 소재로 사용한다.
서사는 이어지지만, **각 주차는 독립적으로 실행 가능**하다. 매 주차 시작 시점에
해당 주차용 스냅샷(스타터 코드 / VM·Docker 이미지 / 패킷 캡처 파일 등)을
제공하므로, 이전 주차를 완료하지 못한 학생도 그 주 실습을 수행할 수 있다.

```
1주 자산식별 ─▶ 2주 서버 하드닝 ─▶ 3주 트래픽 캡처(pcap) ─┐
                                                          │(재사용)
4주 웹취약점 ─▶ 5주 코드보안 ─▶ 6주 악성코드 ─▶ 7주 암호 ─┤
                                                          ▼
8주 결제/HTTPS ──────────────────────────▶ 9주 IDS (3주 pcap 재생)
        │(결제 로그)                                      │
        └──────────────────────▶ 11주 포렌식 ◀───────────┘
10주 IoT·AI ─▶ 12주 사회공학 ─▶ 13주 위험평가·정책(전체 종합)
```

### 주차 간 자산 재사용

| 생성 주차 | 산출물 | 재사용 주차 |
|---|---|---|
| 3주차 | 로그인 트래픽 pcap | 9주차 Suricata 탐지 룰 검증 |
| 8주차 | 결제 서버 접근/에러 로그 | 11주차 침해 타임라인 재구성 |
| 4·5·8주차 | 발견한 취약점 목록 | 13주차 위험평가 매트릭스 입력 |
| 2·8주차 | 하드닝·헤더 설정 | 13주차 보안정책 문서 근거 |

## 대상 및 환경

- **대상**: 전공 고학년 (JS/Python 기본 문법 및 CLI 사용 능숙)
- **환경**: 개인 노트북 + VirtualBox/Docker 사용 가능
- **공통 준비물**: Node.js 20 LTS, Docker Desktop, Git, VS Code,
  VirtualBox(3·9주차용), Wireshark(3주차용)

## 각 주차 운영 구조 (2단)

1. **수업 중 랩 (50~90분)** — 강의실에서 조교 지도 아래 완결하는 가이드 실습.
   감을 잡는 것이 목표. 결과 스크린샷 + 짧은 워크시트 제출.
2. **주간 과제 (2~3시간)** — 수업 후 개인 수행. 코드/설정 파일 + 실행 결과
   캡처 + 1~2쪽 보고서 제출.

## 공통 명세서 템플릿

각 주차 파일(`NN-주제.md`)은 다음 7개 섹션으로 구성된다.

1. **학습 목표** — 이 주차를 마치면 무엇을 할 수 있는가
2. **사전 준비물** — 도구, 스타터 자산, 선행 지식
3. **수업 중 랩** — 단계별 가이드 절차
4. **주간 과제** — 개인 수행 과제와 단계
5. **제출물** — 정확히 무엇을 어떤 형식으로 제출하는가
6. **채점 루브릭** — 배점 기준표
7. **흔한 오류 / 확장 과제(심화)** — 자주 막히는 지점과 우등생용 추가 도전

## ⚠️ 윤리 및 법적 고지 (전 주차 공통)

- 모든 공격 실습은 **본인이 통제하는 격리 환경(로컬 VM/컨테이너)** 안에서만 수행한다.
- 실제 타인의 시스템·계정·네트워크를 대상으로 하는 행위는 **정보통신망법 위반**이며
  즉시 F 및 징계 대상이다.
- 12주차 피싱 메일 제작은 **교육 목적 산출물**이며 **실제 발송은 절대 금지**한다.
- 악성코드 샘플(6주차)은 **네트워크가 차단된 VM**에서만 다루고, 실습 후 스냅샷을 폐기한다.
