# 3주차 실습 — 네트워크보안

## 1. 학습 목표

- 패킷 캡처로 **평문 전송의 위험**을 눈으로 확인한다.
- 포트 스캔으로 공격 표면을 식별하고, 방화벽으로 이를 최소화할 수 있다.
- 스캔/방화벽 적용 전후를 비교하고, **캡처한 pcap을 9주차 IDS 실습에 재사용**한다.

## 2. 사전 준비물

- Wireshark, nmap
- Docker Compose (`starter/shopguard-net/docker-compose.yml`): 평문 HTTP 로그인을 하는
  ShopGuard 웹서버 + 클라이언트 컨테이너
- 도구: `ufw` 또는 `iptables`
- 선행 지식: TCP/IP 기본, 포트 개념

## 3. 수업 중 랩 (80분)

> 스타터: `starter/shopguard-net/` (docker-compose + 평문 로그인 서버)

**Step 0.** 프로젝트 루트에서 제출 폴더를 만든다.
```bash
cd /path/to/workISTutorial
mkdir -p week03
```

### Lab 3-A. 평문 자격증명 캡처 (35분)

**Step 1.** 평문 로그인 서버를 띄운다.
```bash
docker compose -f starter/shopguard-net/docker-compose.yml up
# → http://localhost:8080 (평문 HTTP)
```

**Step 2.** Wireshark를 실행하고 **`Loopback: lo0`**(macOS) 또는 Docker 브리지
인터페이스에서 캡처를 시작한다. 디스플레이 필터를 걸어둔다.
```
http.request.method == "POST"
```

**Step 3.** 브라우저로 `http://localhost:8080` 접속 → 아이디 `alice`, 비밀번호
`Sup3rSecret!` 로 로그인한다.

**Step 4.** Wireshark에서 방금 POST 패킷을 클릭 → 우클릭 **Follow ▸ HTTP Stream**.
요청 본문에서 `username=alice&password=Sup3rSecret!` 가 **평문으로** 보이는 것을 확인한다.

**Step 5.** `File ▸ Save As` 로 `week03/login-plaintext.pcapng` 저장한다. **→ 9주차 재사용**

### Lab 3-B. 포트 스캔 (25분)

**Step 6.** 대상의 열린 포트를 스캔한다(로컬 대상).
```bash
nmap -sV -p 1-10000 localhost      # 8080(web), 2222(scan target) 노출 확인
```
결과에서 서비스·버전을 목록화하고, 불필요하게 열린 포트를 식별한다.

### Lab 3-C. 방화벽으로 최소 개방 (20분)

**Step 7.** (컨테이너 내부 또는 VM에서) `ufw`로 기본 정책을 deny로 두고 웹만 허용한다.
```bash
docker exec -it sg-net-web sh -c "apt-get update && apt-get install -y ufw"
docker exec -it sg-net-web sh -c "ufw default deny incoming && ufw allow 80/tcp && ufw --force enable"
```

**Step 8.** nmap을 재실행해 차단된 포트를 확인하고 Before/After를 비교한다.
```bash
nmap -sV -p 1-10000 localhost
```

**Step 9.** (정리)
```bash
docker compose -f starter/shopguard-net/docker-compose.yml down
```

**랩 제출물**: Step 4 평문 노출 캡처 스크린샷 + Step 6/8 nmap Before/After 결과.

> 💡 Docker Desktop(macOS/Windows)에서는 컨테이너 트래픽이 VM 내부에 있어 호스트
> Wireshark로 안 잡힐 수 있다. 이때는 리눅스 VM에서 compose를 띄우고 그 VM의 NIC를
> 캡처하거나, `tcpdump -i any -w week03/login-plaintext.pcapng port 8080` 로 대체한다.

## 4. 주간 과제 (2.5시간)

### 과제 1. 포트 최소 개방
- 방화벽 규칙을 작성해 ShopGuard가 **웹(80/443)과 관리용 SSH(22)만** 노출하도록 한다.
- 적용 전/후 `nmap -sV` 결과를 표로 비교하고, 각 규칙의 목적을 주석으로 설명한다.

### 과제 2. 평문 → 암호화 분석
- 3-A에서 캡처한 pcap을 분석해 **어떤 정보가 노출되었는지 목록화**한다(자격증명, 세션 쿠키, 상품 검색어 등).
- HTTPS로 전환하면 이 중 무엇이 보호되고 무엇이 여전히 노출되는지(예: SNI, 목적지 IP) 서술한다.

## 7. 흔한 오류 / 확장 과제

**흔한 오류**
- Docker 브리지가 아닌 실제 물리 NIC를 캡처해 트래픽이 안 잡힘 → 올바른 인터페이스 선택.
- `ufw enable` 시 SSH 규칙을 먼저 안 넣어 원격 접속 차단(로컬 컨테이너라 영향은 적으나 원칙 숙지).

**확장 과제 (심화)**
- ARP 스푸핑(격리 네트워크 내)으로 중간자(MITM) 위치를 확보해 평문 트래픽을 가로채는 과정을 재현하고, 이것이 왜 HTTPS로 완화되는지 설명한다.
- `nmap` NSE 스크립트로 서비스 취약점 스캔을 수행하고 결과를 해석한다.
